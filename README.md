# Lime Sync

![Lime Sync](./lime-sync.svg)

Lime Sync is a SQLite-native sync server for the Zero client.

**[Read the documentation](https://lime-sync.natewienert.workers.dev)** · **[Engine source and releases](https://github.com/natew/orez)** · **[Report an issue](https://github.com/natew/lime-sync/issues)**

The current engine, package publication, and documentation website live in
[Orez](https://github.com/natew/orez). Its main-branch CI builds and deploys the
website on each push. Verified build evidence is published only after its
required checks pass.

This repository is the public documentation and issue home. The files in
[`docs/`](./docs) mirror the Lime Sync documentation in Orez; edit the
[source in Orez](https://github.com/natew/orez/tree/main/site/data/lime-sync-docs)
to update both. The mirror checks hourly for documentation changes, while the
website deploys from Orez without waiting for the mirror.

The original standalone engine snapshot is preserved in the
[`archive/engine-snapshot-2026-10-16` branch](https://github.com/natew/lime-sync/tree/archive/engine-snapshot-2026-10-16).
It is historical and does not represent the current engine or release process.
